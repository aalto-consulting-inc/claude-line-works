# LINE WORKS 掲示板ダイジェスト

LINE WORKS の掲示板(Board)から投稿を読み取り、要約・検索・整理するためのスキル。
利用者は非エンジニアが多い。専門用語(API、cursor、boardId など)を出さず、掲示板名・投稿タイトル・日付で会話する。

## 使えるツール(line-works MCP サーバー)

1. `list_boards` — 掲示板の一覧(まずこれで対象掲示板を絞り込む)
2. `list_posts` — 特定の掲示板の投稿一覧(`cursor` で続きを取得、count 最大 40)
3. `get_post` — 投稿の本文(HTML を Markdown に変換して返る)
4. `list_recent_posts` — **利用者が「新規投稿通知 ON」に設定している掲示板からの新着投稿**(通知未設定なら空になる。通知設定していれば「最近のお知らせ」の入口として便利)
5. `authorize` — 初回や有効期限切れのときのログイン認可

## 手順

1. **認可エラーが出たら**: `authorize` を実行して表示された URL を利用者に提示し、「この URL をブラウザで開いて LINE WORKS にログインしてください」と案内する。ブラウザがエラーページになった場合は、そのページの URL をコピーしてもらい `authorize` の `code_or_url` に渡す。
2. **掲示板の特定**: 利用者が掲示板名をあいまいに言う(「総務の掲示板」など)ことが多い。`list_boards` の結果から名前が近いものを選び、複数候補があれば確認する。
3. **投稿の収集**: まず `list_boards` で対象掲示板を絞り、`list_posts` で投稿一覧を取り、期間や件数の指定(「今週」「直近10件」)に合わせて絞る。本文が必要な投稿だけ `get_post` を呼ぶ(全件取得しない)。「最近のお知らせ全部」のような横断依頼で `list_recent_posts` が空を返した場合は、利用者が新規投稿通知を ON にしている掲示板がないため — 各掲示板の `list_posts` を回して代替する。
4. **要約・出力**: 以下を意識して出力する:
   - 投稿タイトル・投稿日・投稿者を明記する
   - 期限・日時・場所・対象者などのアクション情報を優先して抜き出す
   - 「要対応」「情報共有のみ」を分類すると喜ばれる
   - 元投稿を特定できるよう、掲示板名とタイトルを残す

## 注意

- このプラグインは**読み取り専用**。投稿・編集・削除はできない(頼まれたら「閲覧専用です」と答える)
- **コメントは取得できない**(投稿本文まで)。コメントのまとめを頼まれたら「投稿本文のみ対応しています」と案内する。投稿の `commentCount` でコメントの有無だけは分かる
- 見えている掲示板はログインした本人の権限の範囲。見えない掲示板がある場合は管理者に権限を確認するよう案内する
- 大量の掲示板・投稿を一括で読むと時間がかかる。まず対象を絞ってから本文を取得する
